# Md. Syful Islam — Portfolio

Personal website for **Md. Syful Islam**, Department Manager — Application Development at C.P. Bangladesh Co. Ltd. The site is positioned for Application Development Manager, Engineering Manager, Software Development Manager, Technical Lead, and AI automation roles.

Live: [https://saif01.github.io](https://saif01.github.io)

## Stack

HTML5, CSS3, and vanilla JavaScript only. No frameworks, no jQuery, no build step.

## Structure

```text
index.html
assets/css/style.css
assets/js/main.js
assets/images/
assets/documents/cv.pdf
README.md
```

## Sections

1. Hero
2. About
3. Core Expertise
4. Experience
5. AI & Automation (OpenClaw Agent / KYAZZ)
6. Projects
7. Skills
8. Education
9. Contact

## Features

- Sticky navigation with active section indicator
- Mobile hamburger menu
- Light / dark mode (saved in `localStorage`, respects system preference)
- Scroll reveal, hero motion, architecture pulse, and animated counters
- Project hover states and back-to-top control
- Contact form validation with FormSubmit, falling back to `mailto:`
- `prefers-reduced-motion` support
- SEO metadata, Open Graph tags, and Person JSON-LD

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customization

- Profile copy: `index.html`
- Colors and layout: `assets/css/style.css`
- Interactions: `assets/js/main.js`
- CV file: `assets/documents/cv.pdf`
- Portrait and icons: `assets/images/`
